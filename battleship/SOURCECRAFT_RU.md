# Отдельный репозиторий SourceCraft

**Язык:** [English](SOURCECRAFT.md) · Русский

Эта папка является самостоятельным учебным проектом и не зависит от репозитория курса. У неё нет заранее настроенного удалённого репозитория.

1. Создайте пустой репозиторий в вашей организации SourceCraft и осознанно выберите его видимость. Если вы будете отправлять эту папку целиком, не создавайте второй README при инициализации.
2. Скопируйте точный URL клонирования из SourceCraft.
3. В терминале внутри этой папки выполните `git init`, `git add .`, `git commit -m "Initial game teaching project"`, `git branch -M main`.
4. Выполните `git remote add origin`, указав точный URL клонирования, затем `git push -u origin main`.
5. Студенты могут клонировать/форкнуть только эту игру либо использовать ZIP из курса. Откройте клонированную папку целиком в PyCharm.

Не публикуйте токены, `.venv`, `.idea` или персональные данные студентов. Аутентификацию выполняйте по актуальной документации SourceCraft.

Справка: https://sourcecraft.dev/portal/docs/en/sourcecraft/quickstart и https://sourcecraft.dev/portal/docs/en/sourcecraft/operations/repo-clone
