# Standalone SourceCraft repository

**Language:** English · [Русский](SOURCECRAFT_RU.md)

Suggested repository name: `lab01-battleship`.
This folder is self-contained. It has no dependency on the course repository and no configured remote.

1. Create an empty repository in your SourceCraft organization. Choose its visibility deliberately. Do not initialize it with a second README if you will push this folder.
2. Copy the exact clone URL from SourceCraft.
3. In a terminal in this folder, run `git init`, `git add .`, `git commit -m "Initial game teaching project"`, `git branch -M main`.
4. Run `git remote add origin` followed by that exact clone URL; then `git push -u origin main`.
5. Students can clone/fork this game only, or use its course ZIP. Open the cloned folder in PyCharm.

Do not publish tokens, `.venv`, `.idea`, or private student data. Authentication follows SourceCraft's current instructions.

References: https://sourcecraft.dev/portal/docs/en/sourcecraft/quickstart and https://sourcecraft.dev/portal/docs/en/sourcecraft/operations/repo-clone
