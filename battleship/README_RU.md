# Морской бой

**Язык:** [English](README.md) · Русский

Выполните три TODO прямо в `game.py`. После каждого изменения запускайте игру и локальные проверки.

**Ввод:** Введите строку и столбец 1–10. Флот: 4 однопалубных, 3 двухпалубных, 2 трёхпалубных, 1 четырёхпалубный. Корабли не соприкасаются, включая диагонали.

## Как играть

### Морской бой: найдите все скрытые корабли

Вы ищете скрытый флот на поле 10×10. Выберите клетку для выстрела. Программа запоминает выстрелы и сообщает мимо, попадание или потоплен. Ответных выстрелов соперника в этом проекте нет.

| Длина корабля | Число кораблей | Занято клеток |
| --- | --- | --- |
| 1 | 4 | 4 |
| 2 | 3 | 6 |
| 3 | 2 | 6 |
| 4 | 1 | 4 |

Итого 10 кораблей занимают 20 клеток. Каждый корабль — прямой горизонтальный или вертикальный отрезок. Корабли не накладываются и не касаются друг друга, включая диагонали.

### Двухпалубный корабль не тонет после одного попадания

| Выстрел | Результат |
| --- | --- |
| Корабль в (2,2) и (2,3). Выстрел: 2 2. | Попадание: одна клетка ещё цела. |
| Снова 2 2. | Отказ: здесь уже стреляли. |
| Выстрел: 2 3. | Потоплен: поражены обе клетки. |

Для победы потопите все десять кораблей. Попадание по одному не раскрывает остальные. Вводите строка столбец; номера от 1 до 10.

## Перед программированием
Сначала выберите простое представление данных, затем опишите порядок решения.

### Представление данных

| Что представляем | Тип Python | Почему подходит |
|---|---|---|
| Координата | `tuple[int, int]` | Выстрел и каждая клетка корабля используют одно представление строка/столбец. |
| Корабль | `set[tuple[int, int]]` | Корабль — уникальное множество занятых им клеток. |
| Флот | `list[set[tuple[int, int]]]` | Хранит корабли отдельно, чтобы можно было определить потопление каждого. |
| Принятые выстрелы | `set[tuple[int, int]]` | Не допускает повторного принятого выстрела и поддерживает проверки принадлежности/подмножества. |

### Порядок решения

1. Отклоните выстрелы вне поля и координаты, которые уже есть в множестве выстрелов.
2. Добавьте принятый выстрел ровно один раз.
3. Определите попадание или промах по принадлежности множествам клеток кораблей.
4. Корабль потоплен, когда все его клетки входят в множество принятых выстрелов; завершите игру, когда это верно для каждого корабля.

## Реализация

Откройте `game.py` и выполните три TODO по порядку. Точное задание написано рядом с каждым TODO; остальную логику игры не изменяйте без необходимости.

## Запуск и проверка

```bash
python main.py
python practice_checks.py
python tests.py
python submission_check.py
```

`practice_checks.py` предназначен для пошаговой работы. `tests.py` проверяет полное поведение игры после завершения всех трёх TODO.
